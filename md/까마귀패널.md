# EpicMMO 까마귀 패널 - 스킬트리 효과 연동 개발 노트

## 목표
EpicMMO 까마귀 패널(인벤토리 열면 나오는 캐릭터 패널) 왼쪽 메뉴에 "스킬트리 효과" 버튼을 추가하고,
클릭 시 오른쪽 영역에 직업 효과 / 액티브 스킬 / 패시브 효과를 표시한다.

## 최종 목표 UI
```
[왼쪽 메뉴]         [오른쪽 콘텐츠]
발동중인 효과   →   스킬트리 효과
스킬트리 효과   →   ── 직업 효과 ──
메시지 로그         [배운 직업 스킬들]
                    ── 액티브 스킬 ──
                    [배운 액티브 스킬들]
                    ── 패시브 효과 ──
                    [배운 패시브 스킬들]
```

---

## 확인된 EpicMMO 패널 Unity 구조

```
TextList                          ← 공통 부모
├── SkillList (ScrollRect)        ← 왼쪽 nav 스크롤
│   └── ListRoot                  ← menuContainer (_cachedMenuContainer)
│       ├── [Button] 발동중인 효과
│       └── [Button] 메시지 로그
└── SkillListScroll               ← 오른쪽 패널 루트 (ScrollRect 없음!)
    └── (내부 구조 미확인)         ← 발동중인 효과 내용이 여기 표시됨
```

**로그 증거:**
```
[CSTPanel] TMP 발견: '메시지 로그' @ name
[CSTPanel] 37프레임 후 EpicMMO 패널 발견: ListRoot
[CSTPanel] InjectAll: ListRoot (자식: 2)
[CSTPanel] 공통부모: TextList, 왼쪽SR: SkillList
[CSTPanel] 오른쪽 패널 루트 (ScrollRect 없음): SkillListScroll
```

## 핵심 발견 사항

### 1. EpicMMO 버튼은 TMP_Text 사용
- `UnityEngine.UI.Text` 아님 → `GetComponentInChildren<Text>()` 실패
- `SetButtonText()`가 TMP_Text를 찾지 못해 새 Text 컴포넌트를 추가
- 결과: 원본 TMP "발동중인 효과" + 추가된 UI.Text "스킬트리 효과" 동시 표시
- **Fix 필요**: Reflection으로 TMPro.TMP_Text 찾아서 text 프로퍼티 set

### 2. 버튼 위치 겹침
- EpicMMO 버튼은 VerticalLayoutGroup 없이 절대좌표(anchoredPosition) 사용
- Instantiate로 복제하면 원본과 같은 위치에 겹침
- **Fix**:
  1. firstRt (발동중인효과), secondRt (메시지로그) 위치 차이로 step 계산
  2. newBtn.anchoredPosition = firstRt.position + step (바로 아래)
  3. SetSiblingIndex(1)로 발동중인효과 다음에 삽입
  4. 메시지로그를 step만큼 아래로 이동

### 3. 이중 주입으로 인한 랙
- `InventoryGui.Show`가 두 번 발화 (EpicMMO + 바닐라 각각)
- 두 개의 InjectDelayed 코루틴이 동시 실행
- 각 코루틴이 150프레임 동안 `Resources.FindObjectsOfTypeAll<GameObject>()` 매 프레임 호출
- `FindObjectsOfTypeAll<GameObject>()` = 씬 전체 오브젝트 탐색 → 매우 비쌈
- **Fix 필요**: `_injecting` 플래그로 동시 실행 방지

### 4. 오른쪽 패널 (`SkillListScroll`) 내부 구조 미확인
- ScrollRect 컴포넌트 없음
- 직접 자식에 "발동중인 효과" 콘텐츠가 있는지 미확인
- 우리 패널을 주입해도 EpicMMO 콘텐츠가 계속 표시됨
- **원인 추정**: 자식 Hide 코드가 직접 자식만 처리하는데, 실제 콘텐츠가 더 깊은 계층에 있거나 EpicMMO가 자체 업데이트로 다시 표시

## 다음 개발 시 해결해야 할 것

### 우선순위 1: 버튼 텍스트 수정
```csharp
// SetButtonText에서 TMP_Text 처리 추가
private static void SetButtonText(GameObject btn, string text)
{
    // 1. TMP_Text 찾기 (reflection)
    Type tmpType = null;
    foreach (var asm in AppDomain.CurrentDomain.GetAssemblies())
    { try { tmpType = asm.GetType("TMPro.TMP_Text"); if (tmpType != null) break; } catch { } }

    if (tmpType != null)
    {
        var textProp = tmpType.GetProperty("text");
        var tmpComps = btn.GetComponentsInChildren(tmpType, true);
        if (tmpComps != null && tmpComps.Length > 0)
        {
            foreach (Component c in tmpComps)
                textProp?.SetValue(c, text);
            return;
        }
    }
    // 2. UI.Text 폴백
    var txt = btn.GetComponentInChildren<Text>();
    if (txt != null) { txt.text = text; return; }
    // 3. 새 Text 생성
    // ...
}
```

### 우선순위 2: 이중 주입 방지
```csharp
private static bool _injecting = false;

private static IEnumerator InjectDelayed(GameObject root)
{
    if (_injecting) yield break;  // 이미 실행 중이면 스킵
    _injecting = true;
    try
    {
        for (int attempt = 0; attempt < 150; attempt++)
        {
            yield return null;
            var mc = TryFindMenuContainerGlobal();
            if (mc == null) continue;
            InjectAll(mc);
            yield break;
        }
    }
    finally { _injecting = false; }
}
```

private static void LogHierarchy(Transform t, int depth = 0)
{
    string indent = new string(' ', depth * 2);
    Plugin.Log?.LogInfo($"{indent}{t.name} [SR:{t.GetComponent<ScrollRect>()!=null}]");
    foreach (Transform child in t)
        LogHierarchy(child, depth + 1);
}
